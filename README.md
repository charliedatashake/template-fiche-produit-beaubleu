# Template fiche produit Beaubleu

Maquette des bonnes pratiques SEO et GEO pour le nouveau template produit Beaubleu (refonte de janvier 2027), sur la base de la fiche Ecce Lys.

Les encadrés jaunes sont des notes datashake, masquables avec le bouton en haut de page. Les textes entre crochets sont à compléter par Beaubleu. Page en noindex.

Voir aussi le template article : https://charliedatashake.github.io/template-article-beaubleu/
